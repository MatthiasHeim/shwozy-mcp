Connect to Claude Code

Get set up in under a minute

1 Get the Shwozy App

Download Shwozy on your phone to start recording voice notes with AI actions.

App Store - Coming Soon Play Store - Coming Soon

2 Generate API Key

In the Shwozy app, go to Settings → API Keys and tap "Generate API Key". Copy it - you'll need it below!

Generate Your Claude Code Config

{
  "mcpServers": {
    "shwozy": {
      "url": "https://shwozy-mcp-production.up.railway.app/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY_HERE"
      }
    }
  }
}

3 Add to Claude Code Settings

Open Claude Code settings (~/.claude/settings.json) and add the MCP server configuration. Then restart Claude Code and you're ready to go!
